# 01 企画・要件定義

## このフォルダに書くこと
- 企画: 誰の、どんな課題を解決するか（ターゲット、提供価値）。マネタイズの方法、競合、予算、スケジュールの大枠
- 機能要件: ユーザーが直接触れる機能の一覧
- 非機能要件: セキュリティ基準、対応環境、速度、想定の同時アクセス数、運用コスト
- 受入テストの観点: 要件ごとに「何ができれば合格か」（08で使う）
