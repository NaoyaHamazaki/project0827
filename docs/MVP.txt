# 受付・入退室管理システム MVP要件定義書

## 1. プロダクト概要

コワーキングスペース（例：エキスパートオフィス等）の現行の「物理カード＋有人受付」の運用をそのまま活かし、受付スタッフの台帳確認・手動記帳の負担を軽減するためのスモールスタート用Webアプリ。

---

## 2. 実装スコープ（MVPで実現すること）

* **受付スタッフによるスキャン受付**: バーコードまたはICカード（FeliCa等）をリーダーで読み取り、瞬時に会員情報と入退室を判定・記録する。
* **管理者による会員マスタ管理**: 会員情報の登録・編集・カードIDの紐付け。
* **リアルタイム在室一覧**: 現在館内にいる会員の可視化。

---

## 3. ユーザーロール（権限）

1. **受付スタッフ（Operator）**: スキャン処理、当日の在室確認
2. **管理者（Admin）**: 会員データ管理、ログ閲覧・CSVエクスポート

---

## 4. 画面構成（主要3画面）

### ① 受付スキャン画面

* **主な要素**:
* スキャン入力待受エリア（バーコードリーダー / キーボードフォーカス）
* 判定結果表示パネル（大文字で「会員名」「所属」「有効/無効」を視覚的に表示：成功時は緑、エラー時は赤）
* 入退室ステータス自動切替（前回が「入室」なら次は「退室」に自動トグル）
* 直近の打刻ログ一覧（直近5件程度をリアルタイム表示）



### ② 会員管理画面（管理者用）

* **主な要素**:
* 会員一覧テーブル（氏名、所属企業、カードID、ステータス）
* 検索・絞り込み機能（氏名や企業名での部分一致検索）
* 新規登録・編集モーダル（氏名、所属、バーコード/ICカードIDの紐付け）



### ③ 在室・ログ管理画面（管理者用）

* **主な要素**:
* タブ切り替え：「現在の在室者」 / 「過去の入退室履歴」
* 履歴の絞り込み（日付指定、会員名検索）
* CSVダウンロードボタン（履歴データの出力）

## 5. データベース設計（テーブル定義）

### `members` テーブル（会員マスタ）

| カラム名 | データ型 | 制約・備考 |
| --- | --- | --- |
| `id` | UUID / INT | プライマリキー |
| `name` | VARCHAR | 会員名 |
| `company_name` | VARCHAR | 所属企業・テナント名 |
| `card_identifier` | VARCHAR | UNIQUE, バーコード文字列またはICカードのIDm |
| `status` | VARCHAR | `active`（有効） / `inactive`（無効） |
| `created_at` | TIMESTAMP | 登録日時 |

### `staffs` テーブル（スタッフ・管理者マスタ）

| カラム名 | データ型 | 制約・備考 |
| --- | --- | --- |
| `id` | UUID / INT | プライマリキー |
| `name` | VARCHAR | スタッフ名 |
| `email` | VARCHAR | UNIQUE, ログイン用メールアドレス |
| `password_hash` | VARCHAR | パスワードハッシュ |
| `role` | VARCHAR | `admin`（管理者） / `operator`（受付） |

### `access_logs` テーブル（入退室履歴）

| カラム名 | データ型 | 制約・備考 |
| --- | --- | --- |
| `id` | UUID / INT | プライマリキー |
| `member_id` | UUID / INT | 外部キー (`members.id`) |
| `type` | VARCHAR | `check_in`（入室） / `check_out`（退室） |
| `scanned_by` | UUID / INT | 外部キー (`staffs.id`, NULL許容) |
| `created_at` | TIMESTAMP | 打刻日時 |

---

## 6. 非機能要件・技術方針

* **デバイス**: 受付にタブレット（iPad等）またはPCを設置し、USB/BluetoothのバーコードリーダーまたはICリーダー（Sony PaSoRi等）を接続。
* **レスポンス速度**: スキャンから判定・画面描画までを1秒以内に完了させること。
* **インフラ**: クラウドホスティング（Vercel, Render, AWS等）を利用したWebアプリケーション（PWA対応）。
