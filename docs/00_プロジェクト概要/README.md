## プロジェクト
- 名前: project0827（コワーキング受付・入退室管理／セキュリティカード貸出管理）
- 目的: コワーキングスペースの受付業務（入退室の記録、カード貸出、会員との連絡、会議室予約、ドリンク注文）を、ひとつのWebアプリで電子化し、受付の手間を減らす。
- 説明: Django + React のWebアプリ。スマホ・PCのブラウザで動く。Railway にデモを公開している。
