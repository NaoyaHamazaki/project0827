## 4. テスト範囲外・既知の制限事項

以下は今回のテスト対象外とする。

- **ICカードリーダー（RC-S380/PaSoRi）実機連携**: ローカルPCへの物理リーダー接続が必要なため、
  ブラウザ操作のみのPlaywrightテストでは検証できない。手動確認事項として別途扱う。
- **QRコードのカメラ読取そのもの**: 実カメラでQRコードを読み取る動作は自動テストで再現が難しいため、
  「カメラ映像が起動しQR読み取り待機UIが表示されること」の確認までとし、実際のデコード動作は
  スキャンAPIの直接呼び出し（バックエンド側の`resolve_qr_token`ロジック）またはコード上のカードID直接入力で代替確認する。
- **日本語/英語切替（i18n）**: 実装済みだが、運用上の判断で現在UIから非表示にしている
  （`LANGUAGE_TOGGLE_ENABLED = false`）。今回のテスト対象には含めない。
- **ngrokトンネル・LINE通知ツール**（`tools/ngrok_tunnel/`）: スマホ実機確認用の補助ツールであり、
  アプリ本体の仕様ではないため対象外。
- **バックエンド自動テスト（`manage.py test`）の一部失敗**: `access`アプリの8件（下記）は、
  「入室時にセキュリティカードの選択が必須」という仕様が後から追加された際にテストコード側が
  追随できていないことが原因の**既知の問題**であり、アプリの実際の動作（本仕様書のテストケース）には
  影響しない。実際の挙動はPlaywrightによる本仕様書のテストで別途確認する。
  - `test_scan_toggles_check_in_then_check_out` ほか、`access/tests.py`内のスキャン関連7〜8件
  - 別途バックエンドテストコードの改修は今回のスコープ外とする（必要であれば別タスク化する）
