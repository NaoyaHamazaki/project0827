# 運営者ヒアリングシート（project0827）

作成日：2026-09-04
対象：コワーキングスペース運営者（決裁者）
所要時間目安：10〜15分

## このヒアリングの目的

前回、受付スタッフから「会員カードを受け取ったらセキュリティカードを渡し、番号を紙に手書きで記録している」という実態を聞いた。これは入退室管理ではなく**セキュリティカードの貸出・返却管理**であり、方向性はほぼ固まった。

ただし受付スタッフの動機は「面倒」であり、決裁者（運営者）の動機は「損失」。ここでは**お金を出す側が困っている具体的な事実**を確認し、有償導入の是非を判断する材料を得る。

**このヒアリングでは製品を売り込まない。** 現状の困りごとと数字を聞き取ることに徹し、1回の会話で「継続検討 or 見送り」の判断材料を揃える。

---

## 質問リスト

### 1. 紛失・未返却の実態（損失コストの根拠）
- 「セキュリティカードが返却されないことは、これまでありましたか？」
- （ある場合）「どのくらいの頻度で起きていますか？直近半年〜1年で何回くらいですか？」
- 「そのときはどう対応されていますか？（再発行、鍵交換、そのまま放置など）」
- 「再発行や対応にかかるコストや手間はどれくらいですか？」

### 2. 紙の記録の使われ方（監査・記録価値の有無）
- 「その手書きの記録は、後から見返すことはありますか？」
- 「どんなときに見返しますか？（トラブル発生時、月末の集計、監査対応など）」
- 「見返す際、探すのに時間がかかったりしますか？」

### 3. 業務量（手間の総量）
- 「1日あたり、カードの貸し出しは何件くらいありますか？」
- 「曜日や時間帯で混む時間はありますか？（朝の出社ラッシュなど）」

### 4. 受付の有人体制（無人時間帯の価値提案の分岐点）
- 「受付は営業時間中、常に人がいる状態ですか？」
- 「無人になる時間帯はありますか？その間の貸出・返却はどう扱っていますか？」

---

## 聞けたら深掘りしたい項目（時間に余裕があれば）

- 「今の紙の運用で、正直困っていることはありますか？」（自由回答・本音を引き出す）
- 「もし今の手書き管理が自動化されて、リアルタイムで『今何枚外に出ていて誰が持っているか』が分かるとしたら、価値を感じますか？」
- 「他の拠点や施設でも同じような貸出管理をしていますか？」（複数拠点展開の仮説検証、聞ければで良い・深追いしない）

## 判断基準（このヒアリング後に自分で判断する軸）

- 未返却・紛失が実際に発生していて、コストとして認識されている → 開発着手の根拠が強い
- 紙の記録をほぼ見返さない・紛失もほぼ無い → 「困っていない」ので見送りが妥当
- 決裁者が「お金を払ってでも解決したい」と明言しない限り、次のステップ（画面イメージ提示や開発着手）には進まない
