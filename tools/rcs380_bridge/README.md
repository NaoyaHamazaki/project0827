# RC-S380 (PaSoRi) 受付連携ブリッジ

RC-S380はバーコードリーダーのようなキーボード入力エミュレーションを行わないため、
このフォルダの `agent.py` がカードのIDm読み取り→キーボード入力送信を代行する。
受付スキャン画面（フロントエンドの `/` 画面）は入力欄が常時オートフォーカスされる
作りになっているため、フロントエンド側の変更は不要（画面表示用の状態確認バナーのみ追加）。

## 方式について（重要）

当初はSony純正のPC/SCドライバ経由（`pyscard`）での読み取りを試したが、
このドライバはJPKI（マイナンバーカード）向けで、FeliCaのPolling命令には
対応していなかった（IDmが読み取るたびに変わる不正な値になる）ことが判明した。
そのため、RC-S380を直接サポートする **nfcpy**（USB/libusb経由）を使用する。

nfcpyを使うには、Windows上でこのUSBデバイスのドライバを **WinUSB** に
置き換える必要がある（後述のZadigの手順）。この置き換えを行うと、
**同じリーダーをJPKI（マイナンバーカードの公的個人認証）ソフトで使う機能は
使えなくなる**。このPCでJPKIを日常的に使わないことを確認した上で進めること。
元に戻す手順も下記に記載している。

## セットアップ

### 1. ドライバをWinUSBに置き換える（Zadig）

1. [Zadig](https://zadig.akeo.ie/) をダウンロードして実行する（インストール不要、exeを直接実行）
2. 上部メニュー「Options」→「List All Devices」にチェックを入れる
3. デバイス一覧から **「NFC Port/PaSoRi 100 USB」**（USB\VID_054C&PID_06C3）を選択する
   - **他のデバイスは絶対に選択しないこと**。関係ない機器のドライバを壊す恐れがある
   - 「Sony FeliCa Port/PaSoRi 3.0 0」という名前の別項目（SoftwareDevice）は対象外
4. 右側のドライバ選択欄で **WinUSB** を選ぶ
5. 「Replace Driver」（または「Install Driver」）をクリックする
6. 完了したらPCを再起動するか、USBケーブルを一度抜き差しする

元に戻す場合: デバイスマネージャーで対象デバイスを右クリック→「ドライバーの更新」→
「コンピューターを参照してドライバーを検索」→「コンピューター上のデバイスドライバーの一覧
から選択」から、Sony純正ドライバー（FeliCa Port/PaSoRi）を選び直す。
見つからない場合はSony公式のPaSoRiドライバーインストーラーを再実行する。

### 2. Pythonパッケージのインストール

```powershell
cd tools\rcs380_bridge
python -m venv venv
.\venv\Scripts\pip install -r requirements.txt
```

## スクリプト

- `read_idm.py`: 動作確認用。カードをかざすとIDmとタグ種別をコンソールに表示するだけ。
- `agent.py`: **本番用。これを常駐させておくだけでよい。** 起動すると同時に
  カード検知ループ（`reader_loop.py`）を内部スレッドで自動開始し、ブラウザ操作なしで
  スキャン可能な状態になる。受付スキャン画面はこのサービス（`http://127.0.0.1:5577`）に
  状態を問い合わせ、万一ループが停止していた場合のみ「起動する」ボタンで再開できる
  （USB抜き差し直後などの復旧用。通常は表示されない）。
- `bridge.py`: 手動実行・デバッグ用。agent.pyと同じ処理をコンソールに出力しながら
  フォアグラウンドで動かす。通常運用では使わなくてよい。
- `reader_loop.py` / `felica_nfc.py`: 上記から共通で使う読み取りロジック。

まずは `read_idm.py` で、同じカードを何度かかざしても**毎回同じIDm**が表示されることを確認する。

```powershell
.\venv\Scripts\python read_idm.py
```

## 起動方法

ブラウザ（JavaScript）はセキュリティ上ローカルのプロセスを直接起動できないため、
`agent.py`だけは何らかの形で先に起動しておく必要がある（これはブラウザ側の制約であり、
回避する方法はない）。用途に応じて2通りの方法を用意した。

### A. デスクトップから1クリックで起動（推奨・受付スタッフ向け）

`launch.vbs` は「`agent.py`を起動」→「受付スキャン画面をブラウザで開く」を1回の
ダブルクリックで行う。**既に起動済みの場合は何もせず、単にブラウザを開くだけ**になる
（`agent.py`側で二重起動を検知して無害化しているため、毎朝ダブルクリックしても問題ない）。

1. `launch.vbs` を右クリック→「ショートカットの作成」
2. 作成されたショートカットをデスクトップに移動する
3. （任意）ショートカットを右クリック→「プロパティ」→「アイコンの変更」で分かりやすいアイコンに変更
4. 以降は毎回このアイコンをダブルクリックするだけでよい

`launch.vbs`内のURL（`http://localhost:5827/`）は開発中のものなので、本番運用のURLが
決まったら書き換えること。

### B. Windows起動時に自動実行（バックオフィス向け・完全に手を離したい場合）

1. `Win+R` → `shell:startup` でスタートアップフォルダを開く
2. `agent.py`（このフォルダの`launch.vbs`ではなく）だけを起動する用の`.vbs`を作成して置く

   ```vbscript
   CreateObject("WScript.Shell").Run _
     """C:\Users\right\OneDrive\Desktop\Python\project0827\tools\rcs380_bridge\venv\Scripts\pythonw.exe"" " & _
     """C:\Users\right\OneDrive\Desktop\Python\project0827\tools\rcs380_bridge\agent.py""", 0, False
   ```

3. 次回のWindowsログインから自動で常駐する。ブラウザで受付画面を開くだけでスキャンできる

## 動作の仕組み

- カードをかざしてから離すまでの一連のタップを1回のスキャンとして扱う
  （置きっぱなしにしても連打にならない）
- 同じカードで再度入退室を打刻したい場合は、一度カードを離してから再度かざす

## 運用上の注意

- 受付スキャン画面以外のウィンドウがアクティブな状態でカードをかざすと、
  そちらにIDmが入力されてしまうため、受付PCはスキャン画面専用（キオスク運用）にするのが望ましい
- 会員のカードIDには、`read_idm.py` や実際のスキャンで得られる16桁の16進数IDmをそのまま
  会員管理画面の「バーコード / ICカードID」に登録する
